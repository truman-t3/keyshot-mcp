## Renders / 渲染图

`brass.png` and `steel.png` were rendered locally for the KeyShot MCP documentation
on 2026-10-13 using KeyShot 14.1.0.154. Both are 1440 × 1080 at 64 samples,
with the same Isometric camera, 62° field of view and startup environment.

The glass was corrected using the locally installed `Glass Basic White` material.
The brass image retains the original metal texture; the steel image changes only
that object to `Steel Brushed`. The glass material remains unchanged between the
two saved scenes. These images demonstrate object targeting, not perfect glTF
shader migration or automatic design evaluation.

两张图片由本地 KeyShot 生成，使用同一相机、视野角、环境及渲染参数。先修正玻璃，
黄铜图保留原始金属贴图，拉丝钢图仅替换金属对象，玻璃材质不变。
它们证明指定对象的材质操作，不表示 glTF 自动完整迁移或自动设计评估。
